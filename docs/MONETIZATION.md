# StudentAI — Future Monetization Strategy (Draft / Conceptual)

**Status:** INACTIVE in MVP.  
**Commitment:** Core student utilities will remain free forever with zero paywalls.

---

## 1. Principles of Ethical Student Monetization

Student utilities should prioritize student access and privacy. Any future monetization strategy explored for StudentAI must adhere to these non-negotiable guardrails:

1. **No Paywalls on Fundamental Tools:**
   - CGPA calculation, marks percentage, attendance forecasting, basic Pomodoro, and notes will never be locked behind a paywall.
2. **No Intrusive Surveillance Tracking:**
   - No behavioral profiling, cross-site trackers, or sale of student data.
3. **No Subscription Traps:**
   - Avoid predatory trial subscriptions that auto-bill without clear student consent.

---

## 2. Potential Future Monetization Pathways

### Option A: Ethical, Privacy-Preserving Developer Sponsorships
- **Model:** Integrate privacy-respecting ad networks such as **EthicalAds** or **CarbonAds**.
- **User Impact:** Low. Displays a single text/small banner ad relevant to tech students (e.g., student hosting credits, hackathons, or developer tools).
- **Target Revenue:** Covers domain name registration or cloud sync server costs.

### Option B: Optional Cloud Sync ("StudentAI Sync")
- **Model:** While local storage is free forever, students wishing to sync tasks and notes across mobile and desktop devices could opt for an optional low-cost cloud sync tier (e.g., ₹49/month or ₹299/year).
- **Technology:** Self-hosted encrypted sync or Supabase hobby tier.

### Option C: Bring Your Own Key (BYOK) & Advanced AI Credits
- **Model:** For future advanced features (e.g., automated resume rewrite suggestions or custom mock interview AI examiners):
  - Free users can provide their own free API key (Gemini Free Tier, Groq Free Tier, or local WebLLM).
  - An optional pre-paid AI token pack for students who prefer not to generate their own API keys.

### Option D: Community Backing & GitHub Sponsors
- **Model:** Public open-source support via GitHub Sponsors, BuyMeACoffee, or university innovation grants.
- **User Impact:** Zero impact on tool experience.

---

## 3. Current MVP Policy

The current MVP contains **0 advertisements, 0 subscriptions, and 0 payment gateways**. It operates entirely as an open, accessible public utility.
